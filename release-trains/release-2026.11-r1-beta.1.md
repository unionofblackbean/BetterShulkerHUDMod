# [MC 26.1 / 26.1.1 / 26.1.2 / 26.2.x / 26.3][Mod 2.2.5-beta.5.ux.3 / 2.2.5-beta.7.ux.3] 五版 UX 预览

Java 25 / Fabric 五个 26.x 版本的 **beta 预览**。26.1.1 使用 Mod 2.2.5-beta.7.ux.3，其余四版使用 2.2.5-beta.5.ux.3；每个主 JAR 只适用于文件名对应的 Minecraft 范围，源码 JAR 仅供阅读，勿装进 mods。卸载该游戏版本的旧版后再安装。

## 更新内容

- 整块 HUD 拖动与边缘吸附布局编辑，完成才保存、取消/Esc 放弃、重置先预览；修复编辑时鼠标/键盘被外部输入处理器提前吞掉。
- 潜影盒/末影箱占槽容量与收纳袋原生权重、紧凑/准确数量切换、物品来源悬停详情，设置按用途分组，沿用既有配置键。
- 修复页脚三储物标签覆盖分类栏；配方书打开时整体临时右移、关闭时恢复手动位置；分类按钮显示真实分类名；空网格说明只在悬停时出现。
- MaLiLib 本模组设置名称的坏注册记录可恢复；匹配版本的可选 Mod Menu 配置按钮可实际打开本模组设置。
- 26.1.2 从仓库原来的 2.0.x 维护线升级为完整 2.2.x 便携存储与服务端协议，**不是只做视觉更新**；1.21.x 五条维护线没有被覆盖或降级。

## 已验证及边界

本地在五版分别完成 build/check、基础客户端、QuickShulker 和对应 Mod Menu 的 Client GameTest：共 15 条客户端 profile，另有五组共享核心断言。详细方法与限制见 [ux.3 验证记录](../docs/ux3/VALIDATION-UX3.md)。26.2/26.3 的真实 Item Scroller JAR 未取得，相关联测 **SKIP**；用户历史显示“-”的具体外部环境成因仍未证明，真实整合包、联机服务端未验收。26.3 仍是候选适配，安装前请备份并核对全部前置版本。遇到问题请提供游戏、模组、Fabric、MaLiLib 版本及完整 latest.log。
