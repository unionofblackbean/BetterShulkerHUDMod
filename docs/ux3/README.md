# 26.x Better Shulker HUD ux.3 预览

该预览覆盖 Minecraft 26.1、26.1.1、26.1.2、26.2.x、26.3.x；不是 1.21.x 更新。使用前核对对应游戏版本、Fabric Loader、Fabric API、MaLiLib 和 Java 25。只安装相应版本**不带 -sources** 的主 JAR，并先移除旧版；26.2.x 的 JAR 不能装到 26.3。

| Minecraft | 本模组预览版本 | Fabric Loader 最低 | MaLiLib 范围 |
| --- | --- | --- | --- |
| 26.1 | 2.2.5-beta.5.ux.3 | 0.19.2 | ≥0.28.1 <0.29.0 |
| 26.1.1 | 2.2.5-beta.7.ux.3 | 0.19.2 | ≥0.28.2 <0.29.0 |
| 26.1.2 | 2.2.5-beta.5.ux.3 | 0.18.4 | ≥0.28.3 <0.29.0 |
| 26.2.x | 2.2.5-beta.5.ux.3 | 0.19.3 | ≥0.29.0 <0.30.0 |
| 26.3.x | 2.2.5-beta.5.ux.3 | 0.19.5 | ≥0.30.2 <0.31.0 |

- HUD 页脚三个存储视图标签作为整体靠右，不压分类；打开配方书时整个 HUD 暂时移到背包右侧，关闭后恢复手动位置。右侧空间不足时整块隐藏，避免看不见的点击区域。
- 分类图标悬停显示对应分类名称；空网格取消常驻灰字，悬停时才说明容器为空、无搜索结果、载入中或内容未知。
- MaLiLib 设置页显示本模组名称；安装**对应 Minecraft 版本**的可选 Mod Menu 后，模组列表的配置按钮可打开设置。旧用户环境中 “-” 的具体外部成因未确定，需在真实整合包再确认。
- 默认 B+C 可打开现有设置页，选择“编辑 HUD 布局”，拖动整块面板；“完成”保存，“取消”/Esc/关闭丢弃，“重置”先预览默认布局。编辑时背包取放和滚轮输入暂停。
- 容量：潜影盒/末影箱按占用槽位计，收纳袋按原生重量；数量可在紧凑 K/M 与完整数字之间切换。悬停条目可查看准确数量、来源容器等详细信息；设置项按用途分组而不改旧配置键。
- 26.1.2 本次从仓库原有 2.0.x 维护分支升至完整 2.2.x 便携存储功能线；这不只是界面更新。用户应先备份配置与存档，再在实际客户端/服务端组合中试用。

五版构建和 15 条客户端测试范围见 [验证记录](VALIDATION-UX3.md)。真实整合包、联机服务端与 26.2/26.3 的 Item Scroller 联测仍需单独验收。完整变更历史见 [Release Notes](../../RELEASE_NOTES.md)。
